
# Portafolio — Ezequiel

Personal developer portfolio built with React and Vite.

The goal of this project is to showcase my technical skills, projects, development experience, and continuous learning journey.

## Sobre el proyecto

Este portafolio es un proyecto personal que busca presentar mi perfil como desarrollador, mostrar los proyectos en los que trabajé y documentar mi evolución profesional.

Además de construir una web funcional, este proyecto me permite poner en práctica buenas prácticas de desarrollo, organización de componentes, diseño responsive, control de versiones y despliegue.

## Metodología de desarrollo

El proyecto se desarrolla de forma incremental, organizando el trabajo en etapas o sprints.

Cada sprint tiene objetivos definidos, tareas específicas y una etapa de revisión para validar los cambios antes de continuar.

El flujo de trabajo contempla:

- Planificación y organización de tareas
- Desarrollo por componentes
- Control de versiones
- Pruebas y revisión visual
- Documentación
- Despliegue

## Ejecución local

Instalar las dependencias:

```bash
npm install
```

Iniciar el servidor de desarrollo:

```bash
npm run dev
```
